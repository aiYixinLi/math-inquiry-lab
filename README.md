# 数学探究实验室 · 公开演示版

一个以盲盒概率、电梯停层和蛋糕公平切分为主题的互动数学探究应用。

- 包含互动学习、模拟实验、测试反馈和盲盒建模阶梯。
- “自由提条件”使用预先录制的 AI 翻译结果供演示，计算和检验在浏览器中完成；此版本不连接 AI 服务。
- 学习进度保存在访问者当前的浏览器中，清除网站数据会删除这些记录。
- 尚无题目的找错练习不显示入口。

## 本地运行

需要 Node.js 20.19 或以上、npm 10 或以上。

```bash
npm ci
npm run dev
```

`npm run test:run` 验证离线回放，`npm run build` 生成 `dist/` 静态文件。公开版通过 Vite 配置固定启用离线演示模式。

## 发布

推送到本仓库的 `main` 分支后，GitHub Actions 会构建并部署到 GitHub Pages。此仓库是研究项目中 Web 应用的独立公开副本；原研究项目的后续修改需要先同步到此仓库，才会触发更新。
